# Bathymetric evolution can induce estuarine mean sea-level change through trends in tidal asymmetry

This repository contains the complete codebase used to produce all results and figures for the paper:

**_Bathymetric evolution can induce estuarine mean sea-level change through trends in tidal asymmetry_**  
_To be submitted in AGU's Journal of Geophysical Research: Oceans_

## Data availability

The DCSM output produced in this study is publicly available at:

https://doi.org/10.4121/799a3854-35a3-40d1-9ef1-7c050d4bca41
